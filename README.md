## Featured project: VisionAI

A real-time navigation assistant for visually impaired users, built at a hackathon. It detects what's ahead and speaks guidance in English, Hindi, Kannada and Bengali. Built with YOLOv8, Flask, React Native and multilingual text-to-speech. I also prototyped a browser version with TensorFlow.js and the Claude API.

## Design and features

- Video-editor style layout: a timeline ruler with a playhead at the top, and each section laid out like a track
- Light and dark mode that follows your device setting
- Responsive layout for phones, tablets and desktops
- Respects reduced-motion settings
- Single self-contained `index.html` file: HTML and CSS only, with the profile photo embedded
- Fonts: Bricolage Grotesque and Figtree from Google Fonts

## Run it locally

1. Clone the repo:
   ```
   git clone https://github.com/MrRouhin/MrRouhin.github.io.git
   ```
2. Open the folder in VS Code.
3. Open `index.html` in your browser, or right-click it and choose **Open with Live Server**.

## Deployment

The site is hosted for free on GitHub Pages from the `main` branch. Pushing a change to `index.html` updates the live site within a minute or two.
